### Worktree and simulator cleanup

You own the disk and the safety checks. Prune merged or abandoned git worktrees and stale iOS simulators to reclaim space. Deletion can't be undone, and nothing reviews it afterwards, so every step guards against deleting something in use or holding uncommitted work.

1. **Snapshot and audit.** Record `df -h /`, then run `<rigor skill dir>/scripts/worktree-audit.sh [repo-path]` (the `build-the-lever` principle). It takes paths from `git worktree list` rather than hand-typed ones, because worktrees also live outside the obvious sibling directory (for example under `.claude/worktrees/` or `~/.codex/worktrees/`). For each worktree it reports size, age, merge state, uncommitted work, PR state, and the date of the newest Claude Code or Codex session that touched it, and suggests a bucket. The transcript scan is slow, so run it in the background.
2. **Treat the bucket as advice, not permission.** Ask the user which sessions and worktrees are still in use and cross-check every candidate against that list (the `prove-it-works` principle). The user's list wins: the audit can mark `safe` a worktree someone still depends on.
3. **Verify usage before deleting.** For every `verify-recent-chat` row, and anything else you doubt, run subagents in parallel to read the relevant transcripts and report whether the session is still ongoing and which worktrees it touches (transcripts are bulky; see the `guard-the-context-window` principle). An active session may have spawned arena or repro work into sibling worktrees through subagents, and those are in use even if nothing names them.
4. **Pause before irreversible loss.** `wip:N` means N tracked files with uncommitted edits: show the diff and get a decision, because a clean worktree can be recreated from its branch but uncommitted work is gone once deleted. `scratch:N` means untracked files, which are usually safe to drop, but name them. Worktrees that are clean, merged, and not in use proceed without asking (per Autonomy); `wip` and in-use worktrees wait for the user.
5. **Prune the confirmed set.** For each path, run `git worktree remove --force <path>`. If the directory survives because of ignored build artifacts, `rm -rf` it, then run `git worktree prune`. Branch refs survive, so no commits are lost. Confirm with `df -h /` and list the worktrees again.
6. **Reclaim simulators and caches.** Simulators are usually the next-largest win: `xcrun simctl --set testing delete all` (XCTest device clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` followed by `xcrun simctl runtime delete <id>` for old runtimes. If more space is needed: Xcode `DerivedData` and `iOS DeviceSupport`, and package caches (pnpm, uv, brew, yarn). Clear only caches the user hasn't asked to keep.

**Reply:** `df -h /` before and after with the space reclaimed, the worktrees pruned, and a one-line reason for each one kept (in use by which session, or uncommitted work).
